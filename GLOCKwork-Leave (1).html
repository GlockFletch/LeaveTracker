GLOCKwork Leave
ABSENCE & HOLIDAY MANAGEMENT

GLOCKwork Leave uses Google Sheets as its database and an Apps Script proxy to communicate with it. Set up your backend once and your whole team can use this tool.

1
Open Google Sheets, create a new spreadsheet and name it GLOCKwork Leave DB. Copy its URL — you'll need the spreadsheet ID (the long string in the URL).
2
In that spreadsheet, go to Extensions → Apps Script. Paste the Apps Script code provided alongside this file. Replace the spreadsheet ID placeholder, then deploy as a web app (Anyone access).
3
Copy the deployment URL and paste it below.

Settings are saved in your browser. Clear site data to reset.
